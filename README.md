# EquiCord AorySpoofer

### Français

**EquiCord AorySpoofer** est un plugin conçu pour simuler une plateforme en mode VR (Virtual Reality).

Il permet de modifier la plateforme détectée par EquiCord afin de reproduire un environnement de type réalité virtuelle.

**Fonctionnalités :**
- Simulation de plateforme VR.
- Spoofing de plateforme.
- Configuration simple et rapide.
- Interface facile à utiliser.
- Conçu pour EquiCord.

### English

**EquiCord AorySpoofer** is a plugin designed to simulate a VR (Virtual Reality) platform.

**Features:**

- Platform spoofing.

- Easy-to-use interface.
